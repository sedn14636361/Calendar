# カレンダー空き日程ボット

Googleカレンダーと連携し、Discord上で **予定の自動表示**・**空き日程の検索**・**月間カレンダー画像の出力** を行うDiscordボットです。

日程調整のたびにカレンダーを見比べる手間をなくすことを目的にしています。「9月で夜が空いている日」をコマンド一つで一覧でき、結果はそのまま調整ツール（伝助など）に貼り付けられる形式でも出力できます。

## できること

| 機能 | 内容 |
|------|------|
| 予定の自動表示 | 今日から90日分をチャンネルに常時表示し、自動で更新 |
| 空き日程の検索 | `/2026-9` などのコマンドで、指定した期間の空き日を一覧 |
| 月間カレンダー画像 | `/c2026-9` でその月の予定状況をPNG画像で出力 |
| コマンド一覧 | `/cmds` で使い方を表示 |

昼（10:00–18:00）と夜（18:00–24:00）を分けて判定します。

**複数のGoogleカレンダーをまとめて扱えます。** `CALENDAR_ID` を「,」区切りにすると、全カレンダーを合算して「どれか1つでも予定があれば埋まっている」と判定します。仕事用とプライベート用を分けている場合でも、空き日を一括で調べられます。

## コマンド例

```
/cmds                コマンド一覧を表示

/2026-9              昼が空いている日
/n2026-9             夜が空いている日
/a2026-9             昼夜とも空いている日
/u2026-9             昼か夜が空いている日

/2026-9r             昼に予定がある日（末尾 r で反転）
/2026-9d             伝助形式で出力（1日1行・曜日つき）

/c2026-9             月間カレンダー画像

/2026-8:2026-9       月単位の範囲（: で範囲指定）
/2026-8.15:2026-9.30 日単位の範囲（. で日にち指定）
```

先頭（`n`/`a`/`u`）・期間・末尾（`r` または `d`）は組み合わせて使えます。指定できる期間は最大12か月です。

## 必要なもの

- Python 3
- Discordアカウントと、ボットを導入するサーバー
- Googleアカウントと、読み取り対象のカレンダー
- 常時稼働させる環境（Render など。無料枠で運用可能）

## セットアップ

設定は3つのサービスを行き来する必要があり、間違えてもデプロイが失敗するまで気づきません。
これを案内するウィザードを同梱しています。

### とりあえず使う：`wizard.html` を開く

ダブルクリックで開くだけです。インストールもコマンドも不要で、ネットにも繋がりません。

- 手順をステップごとに案内します
- 入力値の**形が正しいか**をその場で検査します（鍵JSONが途中で切れていないか、
  チャンネルIDがDiscordのIDとして辻褒が合うか、トークンに空白が混入していないか）
- 最後に Render に貼る環境変数を生成し、ファイルに保存できます

### 実際に使えるかまで確かめる：`setup_wizard.py` を実行

```bash
pip install -r requirements.txt
python3 setup_wizard.py
```

同じ画面が開き、加えて**実際にDiscordとGoogleに接続して確かめます**。
トークンが通るか、MESSAGE CONTENT INTENT がONか、チャンネルが見えるか、
**カレンダーが共有できているか**まで分かります。

HTMLを直接開いただけではこれらを確かめられません。ブラウザから Discord API を
呼ぶことが許可されていない（CORS）ためで、回避できません。

> どちらの使い方でも、入力したトークンや秘密鍵は **このPCの外に出ず、保存もされません**。
> サーバーを使う場合も待ち受けは `127.0.0.1` のみで、ファイルにもログにも書きません。

設定後に不具合を調べるときは、検証だけをコマンドで実行できます。

```bash
python3 setup_checks.py
```

### 手動で設定する

導入手順の詳細は **[GUIDE.md](GUIDE.md)** にまとめています。Discordボットの作成、Googleサービスアカウントの発行、Renderへのデプロイ、常時稼働の設定までを順番に解説しています。

大まかな流れは次のとおりです。

1. Discord Developer Portal でボットを作成し、MESSAGE CONTENT INTENT を有効化
2. Google Cloud で Calendar API を有効化し、サービスアカウントの鍵を発行
3. 対象カレンダーをサービスアカウントのメールアドレスに共有
4. 環境変数4つを設定して起動

```bash
pip install -r requirements.txt
python Calendar.py
```

## 環境変数

認証情報はすべて環境変数から読み込みます。コード内に直接書く箇所はありません。

| 変数名 | 内容 |
|--------|------|
| `DISCORD_BOT_TOKEN` | Discord Bot のトークン |
| `CHANNEL_ID` | 自動表示先チャンネルのID（数値） |
| `CALENDAR_ID` | 読み取り対象のGoogleカレンダーID（「,」区切りで複数指定可） |
| `SERVICE_ACCOUNT_JSON` | サービスアカウント鍵JSONの中身を丸ごと |

> サービスアカウントの鍵ファイル（`service_account.json`）は **リポジトリにコミットしないでください**。`.gitignore` で除外済みです。漏洩するとカレンダーへアクセスされます。

## カスタマイズ

`Calendar.py` 上部の定数を変更するだけで調整できます。

```python
DAYS_TO_SHOW = 90                  # 自動表示する日数
DAY_START, DAY_END = 10, 18        # 昼の時間帯
NIGHT_START, NIGHT_END = 18, 24    # 夜の時間帯
JST = timezone(timedelta(hours=9)) # タイムゾーン
```

画像の配色や寸法も同ファイル内の定数と `render_month_image()` で変更できます。詳細は [GUIDE.md](GUIDE.md) の「カスタマイズできる部分」を参照してください。

## トラブルシューティング

まず `python3 setup_checks.py` を実行してください。環境変数の値で実際に接続し、
どこが問題かを名指しします（値は読むだけで保存しません）。

よくあるエラーと対処は [GUIDE.md](GUIDE.md) の「第III部 エラー対処」にまとめています。
